# 05 — STORYTELLING + LANDING PAGE ARCHITECTURE

## 1. The page is a narrative, not a list of features

Do not design:

Hero → Features → Features → Features → Pricing → Footer

Design a persuasion sequence.

A premium product page should answer, in order:

1. **What is this?**
2. **Why should I care?**
3. **What does it actually do?**
4. **Why is it better?**
5. **Can I trust it?**
6. **What happens when I use it?**
7. **What should I do next?**

---

## 2. Recommended narrative spine

### Act I — Recognition

The hero names the category and the transformation.

Do not write vague AI slogans. State a meaningful outcome.

Example structure:

**Eyebrow:** Built for the way modern teams work

**Headline:** The system that turns complex work into forward motion.

**Supporting line:** One concise explanation of what the product does and who it is for.

**CTA:** Start building / Try the product / See it in action

**Visual:** real product UI

---

### Act II — Evidence

Immediately prove that the product is real.

Use:

- product interactions
- workflows
- realistic states
- customer logos when credible
- metric/data evidence

The visual should do some of the explaining so copy does not have to carry the entire burden.

---

### Act III — The product worldview

Explain how the product thinks about the problem.

This is where an editorial statement can appear:

> “Instead of adding another dashboard, we redesigned the workflow around decisions.”

The goal is to create a point of view, not merely a feature list.

---

### Act IV — Feature chapters

Give each major capability its own visual chapter.

Each chapter should have:

- one idea
- one visual anchor
- one proof interaction
- concise copy

Avoid combining five feature ideas into one card grid.

---

### Act V — Trust

Trust can be established through:

- customer evidence
- product quality
- security information
- reliability metrics
- thoughtful details
- testimonials
- transparent limitations

A premium page does not have to yell “trusted.” It should make trust obvious.

---

### Act VI — Conversion

The final CTA should feel like the natural next step after the story.

Do not introduce a new visual language at the end.

---

## 3. Hero composition patterns

### Pattern A — Type + Product

Large left-aligned statement, product visual underneath or offset.

Best for SaaS and developer tools.

### Pattern B — Centered editorial

Large centered statement, compact supporting copy, strong product frame lower in the viewport.

Best when brand voice is a major differentiator.

### Pattern C — Split narrative

Text occupies one side; dynamic product state occupies the other.

Best when the product interface is visually strong.

### Pattern D — Full-bleed product evidence

Minimal hero copy with the product itself dominating the composition.

Best for products whose UI is the primary proof of quality.

---

## 4. Section transitions

A section should feel like the next chapter, not another rectangle.

Use transitions through:

- background value changes
- spacing
- image scale
- alignment changes
- typography changes
- a small divider or label

Avoid huge decorative dividers.

---

## 5. Copywriting principles

Premium copy is:

- specific
- short
- confident
- calm
- slightly opinionated
- free of hype unless the evidence supports the claim

Avoid:

- “revolutionary”
- “game-changing”
- “next-gen”
- “unlock the future”
- “powered by cutting-edge AI”

These phrases create no information.

Prefer verbs and outcomes:

- plan
- decide
- build
- ship
- analyze
- automate
- coordinate
- discover
- create
- verify

---

## 6. Visual hierarchy of a section

Every section should have:

**1 primary idea**

**1 focal visual**

**1 supporting proof**

Everything else is optional.

---

## 7. Proof density

An expensive landing page usually contains more evidence than decorative illustration.

For every abstract marketing claim, ask:

> Can the product show this instead?

For AI products this is especially important.

Instead of “Our AI understands context,” show an interaction that demonstrates contextual reasoning.
