# 08 — PREMIUM DESIGN QUALITY AUDIT

Score each category 0–5.

## A. Brand presence

0 = generic template
1 = mild personality
2 = recognizable direction
3 = consistent personality
4 = strong point of view
5 = distinctive enough to identify without the logo

## B. Hierarchy

0 = everything competes
1 = weak hierarchy
2 = some structure
3 = clear hierarchy
4 = excellent scanning
5 = hierarchy feels effortless

## C. Typography

Check:

- font choice
- scale
- line breaks
- weight
- tracking
- line height
- contrast
- numerals

## D. Spatial design

Check:

- grid alignment
- content width
- section rhythm
- negative space
- density shifts
- responsive composition

## E. Materiality

Check:

- surfaces
- borders
- shadows
- layering
- texture
- dark mode depth

## F. Product credibility

Check:

- realistic UI
- believable data
- authentic states
- useful details
- clear workflows

## G. Interaction

Check:

- hover
- focus
- active
- loading
- success
- error
- empty state
- reduced motion

## H. Motion

0 = distracting
1 = excessive
2 = acceptable
3 = purposeful
4 = elegant
5 = invisible sophistication

## I. Copy

Check:

- specificity
- brevity
- confidence
- no empty hype
- clear outcome
- strong labels

## J. Engineering polish

Check:

- no layout shift
- no obvious performance issues
- responsive behavior
- semantic HTML where appropriate
- accessible controls
- maintainable tokens
- reusable components

---

## Automatic rejection conditions

Reject and revise when:

- the page resembles a generic AI template
- every section uses the same card layout
- gradients are doing most of the visual work
- the CTA is unclear
- muted text is unreadably faint
- there are decorative elements with no purpose
- animations delay interaction
- product UI is obviously fake or incoherent
- mobile is merely a squeezed desktop
- the design has more visual noise than the content can justify

---

## Final standard

The redesign should be something a senior product designer could plausibly defend in a review with the sentence:

> “Every major visual decision is tied to hierarchy, product behavior, brand character, or storytelling.”

If not, keep refining.
