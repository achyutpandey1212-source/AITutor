# Premium Web Mastery — How to use

This folder is designed to be handed to an AI coding agent together with a web application codebase.

## Recommended usage

Give the agent:

1. `00_MASTER_INDEX.md`
2. all numbered design documents
3. `10_AGENT_BRIEF_TEMPLATE.md` filled with project-specific information
4. the existing codebase
5. screenshots or reference pages when available

Then use this instruction:

> Read the entire Premium Web Mastery pack before modifying the application. Do not copy any reference brand literally. Extract the principles and build an original visual system for this product. Inspect the existing application first, then create a design brief, establish tokens, redesign the highest-leverage page, validate responsive behavior and accessibility, and perform the full quality audit before finishing.

## What this pack deliberately does not prescribe

It does not force every project to use:

- the same font
- the same accent color
- the same page layout
- the same corner radius
- the same illustrations
- the same animation library

The system is **principle-first and token-driven**.

## Research basis

The philosophy was informed by current Apple Human Interface Guidelines and current product/design behavior observable on Notion and Linear. Apple emphasizes purpose, agency, familiarity, flexibility, simplicity, craft, delight, purposeful motion, and accessibility. Notion demonstrates flexible content-first typography and page composition.
